# Glossary

The words the screens use, in plain terms.

| Term | Meaning |
|---|---|
| **Activate (a stage)** | Start timing on a stage: its gates now count for it |
| **Category** | A class that cuts across the main classes (Rookie, Stock) |
| **Check-in** | Registering a car's arrival at the desk on the day |
| **Close (a stage)** | End a stage. Open runs become DNF, cars that never started DNS. Final |
| **Countdown** | A start mode: a marshal starts a countdown per car and the time runs from its end |
| **Disqualified** | Out of the event by a jury decision; removed from every ranking |
| **DNF** | Did not finish: started a stage and didn't reach its finish |
| **DNS** | Did not start a stage |
| **Entry** | A car with its crew, start number, classes and transponders |
| **Event** | One rally. Stored as one file on the server |
| **Freeze (a start list)** | Fix the start list as posted, so later corrections don't move it |
| **Gate** | A box at the track that reports passings |
| **Hand-timed** | A start or finish a marshal set (Start now, Finish now, Correct), marked with a hand icon |
| **Hotspot / emergency Wi-Fi** | The Wi-Fi a gate opens itself when it finds no network, to be set up from a phone |
| **Invitation** | A printed sheet with a QR code that logs a marshal's device in with a role |
| **Jump start** | On a countdown or timetable stage: the car left before its start time |
| **Light barrier** | A sensor across the track; exact, but it can't tell which car passed |
| **Main class** | A class that splits the field (4WD, 2WD) |
| **Notional time** | The time charged for a stage a crew didn't finish: the slowest time on it plus a penalty |
| **Overall** | The ranking over all counted, closed stages: stage times plus penalties |
| **Pairing** | The organiser approving a gate for this server, once |
| **Passing** | A gate noticing something go through |
| **Penalty** | Time added to a crew's overall, from the catalogue or as free text |
| **Pre-start gate** | A gate before the start line that shows which car is waiting there |
| **Provisional** | Printed on results until the rally is closed: they can still change |
| **Qualifying** | A stage ranked on its own that can set the first stage's start order |
| **Scrutineering** | The technical check of a car before it may start |
| **Shakedown** | A trial stage ("Not counted"): as many runs as a car likes |
| **Slot** | A car's start time on a countdown or timetable stage |
| **Split** | A timing point between start and finish |
| **Stage** | One timed section from a start to a finish |
| **Start order** | The order cars start a stage in; printed as the start list |
| **Timetable** | A start mode: every car has a start time, first start plus an interval |
| **Transponder** | A small sender in the car that tells a loop gate which car passed |
| **Unassigned passing** | A passing without a known car, waiting for a marshal to assign it |
| **Void** | Take a run out of the results but keep it as evidence; the car may run again |
| **Withdrawn** | Out of the rally for good (broken down, gone home); keeps the stage times it drove |
