Install an ESP32 gate

Firmware for the Seeed XIAO ESP32-S3.

  1. Connect the board by USB-C, in Chrome or Edge on a laptop.
  2. Install, pick the board's port, and choose to erase the device on a first install.
  3. After a restart the gate raises the Wi-Fi rally-gate-… (password rally-gate). Join it to set the rally network.

This browser can't flash over USB. Use Chrome or Edge on a laptop.

Flashing needs this page over HTTPS.
